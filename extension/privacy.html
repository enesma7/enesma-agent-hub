ENESMA AGENT HUB for Chrome

This extension is for ENESMA Realty agents. It opens the same Agent Hub tools that are on the Hub home page.

What it collects

When you sign in, the extension sends your email and password to the existing ENESMA sign-in service, the same one used by the Agent Hub website and Transaction Center. It does not keep a copy of your password.

After a successful sign-in, the extension stores the same session cookie the website already uses (enesma_sso, 24 hours). If you choose “Trust this device,” it stores the same device cookie the website already uses (enesma_dt, 30 days). Signing out clears the session cookie and tells the sign-in service to end that session. The device cookie stays, which is the same rule as the website.

What it does not do

The extension does not read your email, your Google Drive files, or the pages you visit. It does not sell data, and it does not send your password anywhere except the existing ENESMA sign-in service. Tile names and pictures are loaded from the public Agent Hub site only after you are signed in.
