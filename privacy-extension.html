AGENT HUB

ENESMA AGENT HUB for Chrome

This extension is a public Chrome Web Store listing. Anyone can find and install it. Only an ENESMA Agent Hub account can sign in.

What is not stored or sold

Passwords are not stored. Personal data is not stored or sold.

When you sign in, your email and password are sent to the existing ENESMA sign-in service, the same one used by the Agent Hub website and Transaction Center. The extension does not keep a copy of them.

Cookies

The extension uses only the session cookie on enesmarealty.com. That cookie is enesma_sso. It is the same 24-hour session cookie the Agent Hub website already sets. Signing out clears it and tells the sign-in service to end that session.

If you check “Trust this device,” the extension also sets enesma_dt on enesmarealty.com, the same 30-day device cookie the Agent Hub website already sets. No cookies are read or written on any other site.

What it does not do

The extension does not read your email, your Google Drive files, or the pages you visit. Tile names and pictures are loaded from the public Agent Hub site only after you are signed in.
